Overview

CloudCasa identity

The CloudCasa logo system is designed for clear digital communication across product, marketing, and partner environments. It supports both full wordmark and standalone icon use, with light and dark variants for flexible placement.

  • Use the primary logo for customer-facing and product surfaces.
  • Use the white version on dark backgrounds and overlays.
  • Use the icon when space is limited or branding is already established.

Usage guidance

Primary usage

Use the color logo for websites, sales materials, and product marketing where contrast supports it.

Dark backgrounds

Use the white logo on dark surfaces and in app UI where the icon or wordmark needs stronger contrast.

Icon-only use

Use the standalone icon when the brand is already established in context, such as app favicons or compact dock icons.

Do not distort

Never stretch, rotate, or skew; always scale proportionally and use the approved SVG file when possible.

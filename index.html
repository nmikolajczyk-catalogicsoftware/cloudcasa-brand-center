CloudCasa is Catalogic Software's backup and disaster recovery service for Kubernetes. Delivered as SaaS, it lets teams protect all their clusters and manage backup policies from one place.

The logo comes in two versions: with the "by Catalogic" tagline and without it. Use the tagline version by default; drop it only where Catalogic is already clear from context.

With "by Catalogic"  Default

For anything where CloudCasa appears as a Catalogic product. Horizontal and stacked versions available.

Examples: website, sales decks, datasheets, events, partner co-branding.

Without "by Catalogic"

For places inside the product itself, where the parent brand is already clear.

Examples: app login screen, app store listing, in-product UI, sub-brand use.

Logo Typeface

The wordmark is set in Arcon, always in lowercase. Arcon belongs to the logo only — don't use it for headings, body text, or anything else.

Arcon
Logo wordmark only
✓
cloudcasa

Correct in the logo.

✗
CloudCasa  /  Cloudcasa  /  CLOUDCASA

Never use these casings in the logo.

Do
✓
Always use lowercase

The logo text is "cloudcasa" (all lowercase). This applies everywhere: website, decks, documents, social media.

✓
Respect the exclusion zone

Leave a clear area equal to the height of the letter "l" in "cloudcasa" around all edges of the logo.

✓
Use the gradient version as default

The gradient (purple-to-pink) version is the preferred logo for all digital, web, presentation, and offset print uses.

✓
Use "by Catalogic" lockup for partner/co-brand contexts

When the CloudCasa logo appears alongside partner logos, use the "cloudcasa by Catalogic" stacked variant with associate logo placement rules.

✓
Use white logo on dark or busy backgrounds

Over photography, dark UIs, or colored backgrounds, switch to the all-white version for readability.

Don't
✗
Don't capitalize the logo text

"CloudCasa", "Cloudcasa", or "CLOUDCASA" are all incorrect in the logo context. Always lowercase.

✗
Don't use the gradient on colored backgrounds

On non-white, non-light-gray backgrounds, use either the all-white or single-color (dark) version.

✗
Don't stretch, rotate, or skew the logo

Always scale proportionally. Use the provided SVG files which maintain correct aspect ratio.

✗
Don't use the icon gradient for UI elements

The purple-to-pink gradient is reserved for the CC double-C icon mark. Do not apply it to buttons, headers, or other interface elements.
